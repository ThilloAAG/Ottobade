# OttoBlade website (DividusRX)

Static site: `index.html` is the whole site (images are embedded). No build step.

Deploy: push to GitHub, then Settings > Pages > Deploy from a branch > main / (root).

Before sharing: in `index.html`, replace `https://YOUR-SITE-URL/og-image.png` with your real site URL (used for the preview image on LinkedIn).
